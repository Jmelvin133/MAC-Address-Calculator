What is a MAC Address here?

In Delta Controls systems, a MAC address is a unique node ID (1–127) set physically on each BACnet MS/TP controller using DIP switches. It tells the network which device is which. No two devices on the same trunk can share a MAC address.

Why is address 0 reserved?

Address 0 is used for test mode and network scanning — never assign it to a live device. Addresses 1–127 are valid for controllers.

How to set switches

Each switch represents a bit value (64, 32, 16, 8, 4, 2, 1). Flip the switches whose values add up to your desired address. Example: address 5 = switches 4 + 1 both ON.

  • Switch ON = nub slides down (closed)
  • Switch OFF = nub sits up (open)
  • The leftmost "Not Used" switch (bit 8) should always stay OFF
